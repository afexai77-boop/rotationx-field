# RotationX Field - Build AAB Online (Senza installare Android Studio)

## Come generare l'AAB per Play Console:

1. Vai su github.com e crea un nuovo repository pubblico chiamato `rotationx-field`
2. Carica TUTTI i file di questa cartella (trascina tutto su GitHub: Upload files)
3. Dopo l'upload, vai su Actions (in alto)
4. Vedrai "Build AAB" -> Clicca Run workflow (bottone verde)
5. Aspetta 3-4 minuti
6. In fondo alla pagina dell'azione, scarica l'artifact `app-release-aab`
7. Dentro c'è `app-release.aab` -> quello lo carichi in Play Console > Internal testing

Il keystore usato è rotationx.jks con password RotationX2025! - SALVALO!
